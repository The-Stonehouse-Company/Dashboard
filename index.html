— Setup —

First time? Set up Brevo before your first send

1. Create a free Brevo account at brevo.com (free up to 300/day, unlimited contacts).
2. Verify your sender — Senders → Add a sender → ryan@stonehouserealtyco.com → click the verification link.
3. Authenticate your domain — Senders → Domains → Add stonehouserealtyco.com → copy the 3 DNS records Brevo gives you and paste them into your domain registrar (~15 min, one-time).
4. Import this audience CSV using the button above.
5. Compose your email in Brevo's editor and schedule the send.

Full walkthrough → docs/newsletter-setup.md

Connect to GitHub

Before you can add / edit / delete properties, generate a personal access token.

  1. Open github.com/settings/personal-access-tokens/new (logged in as stonehousecompanyadmin).
  2. Token name: Platinum Reserve Editor. Expiration: pick your preference (1 year is fine).
  3. Resource owner: The-Stonehouse-Company. Repository access: Only select repositories → choose Dashboard.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy the token (starts with github_pat_), and paste it below.
